Notch for Mac 3.4.6

Maintenance and bug-fix release.

- Bug fixes and general improvements
- Improved stability and reliability when the notch opens, closes and reopens
- Better recovery after interruptions, without needing to relaunch
- Smoother handling of mouse and trackpad input around the notch edges
- Reduced memory use and background activity
- Tab bar and tab-order handling tidied up for more consistent behaviour after updates
- Settings are now migrated more safely between versions
- Build and install script hardening
- Internal cleanup and code tidy-ups
- Minor bug fixes
